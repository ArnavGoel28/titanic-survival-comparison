# Titanic Survival Prediction: Naive Bayes vs Logistic Regression

A comparison of Gaussian Naive Bayes and Logistic Regression using shared data preparation and reproducible model notebooks.

## Setup

Use Python 3.12.

```bash
git clone https://github.com/ArnavGoel28/titanic-survival-comparison.git
cd titanic-survival-comparison
```

Windows PowerShell:

```powershell
py -3.12 -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements.txt
```

On macOS/Linux, use `python3.12 -m venv .venv` and `.venv/bin/python -m pip install -r requirements.txt`.

The project is organized around a shared preparation step, separate model notebooks, and a combined metrics report. Results and usage details are added with the completed model stages.
